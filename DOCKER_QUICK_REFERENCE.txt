SERVICES & STARTUP ORDER
───────────────────────────────────────────────────────────────────────────────
1. MongoDB     (Database)      — Health: mongosh ping
2. Redis       (Cache/Queue)   — Health: redis-cli ping
3. ML Service  (Detection)     — Auto-starts (models download 2-3 min first time)
4. Backend API (Express.js)    — Waits for MongoDB, Redis, ML Service
5. Frontend    (Next.js)       — Waits for Backend

All services must be "healthy" before app is fully functional.


TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────
Services won't start
  → Check logs: docker compose logs -f
  → Verify ports available: lsof -i :3001 :3002 :5001 :6380 :27019

Port conflicts
  → Kill process: kill -9 <PID>
  → Or change ports in docker-compose.yml

ML models not loading
  → Normal on first startup (2-3 minutes)
  → Watch logs: docker compose logs -f ml-service

Frontend blank page
  → Rebuild: docker compose up --build frontend
  → Check logs: docker compose logs -f frontend

Health checks failing
  → Check status: docker ps
  → Test manually: docker exec deepfake-backend curl http://localhost:3001/health

PRODUCTION DEPLOYMENT
───────────────────────────────────────────────────────────────────────────────
1. Generate strong secrets:
   openssl rand -base64 32  # JWT_SECRET
   openssl rand -base64 32  # ENCRYPTION_KEY
   openssl rand -base64 16  # ENCRYPTION_IV

2. Update .env.local with:
   NODE_ENV=production
   LOG_LEVEL=error
   FRONTEND_URL=https://your-domain.com
   MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/db

3. Start: docker compose up -d

See DOCKER_DEPLOYMENT_SUMMARY.md for full production guide.
